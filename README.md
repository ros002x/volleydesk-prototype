# Ace

Applicazione statica per la gestione di una societa di volley. Mantiene le aree operative di VolleyDesk con una nuova interfaccia mobile-first.

## Aree

- Dashboard con riepilogo atleti, certificati, quote aperte e incasso stagione
- Roster atleti con ricerca, selezione multipla, cancellazione e modale modifica
- Certificati medici con stato visivo
- Contabilita stagione settembre-agosto con filtri, range date e modifica pagamenti
- Archivio documenti collegato ai file caricati nelle schede atleta
- Deposito dati con anteprima JSON ed export negli appunti

## Avvio

Apri `index.html` nel browser.
